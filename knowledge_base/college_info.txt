## 🏛️ Vision & Mission

### Vision
To empower women through quality education, fostering academic excellence, moral values, and social responsibility, enabling them to become confident, competent, and compassionate leaders in society.

### Mission
- Provide holistic education that integrates academic knowledge with spiritual and moral values
- Foster critical thinking, creativity, and lifelong learning skills
- Promote research and innovation among students and faculty
- Create an inclusive environment that respects diversity and promotes gender equality
- Prepare students for meaningful careers and responsible citizenship

**4. RAG Pipeline**
```python
# rag_pipeline.py
from langchain.chains import RetrievalQA
from langchain.llms import OpenAI

# Initialize vector store
vectorstore = Chroma(persist_directory="./chroma_db", 
                     embedding_function=embeddings)

# Create retriever
retriever = vectorstore.as_retriever(search_kwargs={"k": 5})

# Create QA chain
qa_chain = RetrievalQA.from_chain_type(
    llm=OpenAI(api_key=os.getenv("OPENAI_API_KEY")),
    chain_type="stuff",
    retriever=retriever,
    return_source_documents=True
)
```

**5. Streamlit Web Interface**
```python
# app.py
import streamlit as st
from rag_pipeline import qa_chain

st.title("SJC Tiruppur - AI Chatbot")
st.subheader("Ask anything about St. Joseph's College for Women, Tiruppur")

query = st.text_input("Your question:")

if query:
    response = qa_chain(query)
    st.write("Answer:", response['result'])
    st.write("Sources:", response['source_documents'])
```
