# ST JOSEPH'S AI ASSISTANT 🤖

An AI-powered assistant built using Retrieval-Augmented Generation (RAG) technology.

This project helps users interact with documents and get intelligent answers using Google Gemini AI, LangChain, and FAISS Vector Database.

## Features

- AI chatbot interface
- Document-based question answering
- Semantic search using FAISS
- Gemini AI powered responses
- Streamlit user interface

## Technologies Used

- Python
- Streamlit
- LangChain
- Google Gemini AI
- FAISS Vector Database
- Sentence Transformers

## Project Workflow

User Query
↓
Document Retrieval
↓
Vector Similarity Search
↓
Gemini AI Response
↓
Final Answer
